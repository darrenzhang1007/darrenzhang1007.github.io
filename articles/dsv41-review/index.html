S6. 第 536 行 584 B 的算式把维度与字节混写

  • 原文: 「448 fp8 NoPE + 64 bf16 RoPE + 7 个 64 维 UE8M0 scale + 1 字节 pad = 584 字节」
  • 证据: 逐项相加 448+64+7+1 = 520，与结论 584 差一个 64——因为 bf16 的 64 维 RoPE 占 128 字节（2 B/元素），而 7 个 64 维 scale 才占 7 字节（1 B/scale）。正确写法：448 + 2×64 + 7 + 1 = 584。584/576 这两个数本身与源码注释逐字一致（attention.py:113-118：「584 B, 576 B pages」）。
  • 延伸: 「页 576 B」是 alignment 的 round-up 粒度，584 B 的记录宽 > 576 B 的页名，源码注释同样这么写，属忠实转述；若加一句「576 是对齐粒度、584 是记录宽」会更不易误读。第 535 行的 528 = 512+16 则完全正确（fp8 512 B + 每 32 维 1 B × 16）。
  • [来源: v3 + v5]
